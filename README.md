# 梗友 — 表情包生成器网页原型

这是一个可以直接在 VS Code 中运行的 Next.js 网页项目。

## 在 VS Code 中运行

1. 用 VS Code 打开整个 `meme-friend-web` 文件夹。
2. 打开 VS Code 终端。
3. 第一次运行先执行：

   ```bash
   npm install
   ```

4. 启动开发预览：

   ```bash
   npm run dev
   ```

5. 打开终端里显示的本地网址，通常是 `http://localhost:3000`。

## 当前功能

- 输入朋友说的话
- 上传并预览朋友照片
- 自动识别“仅文字 / 仅图片 / 图片＋文字”三种生成模式
- 每日聚合 Bilibili 热门和百度热搜，筛选人物、口头禅与事件梗候选
- 对话气泡、迷你 emoji、浅粉/暖黄/亮绿滤镜
- 漫画冲击、法庭宣言、抖动故障等艺术字效果
- 生成三张候选表情包
- 选择结果并保存 PNG
- 支持手机和桌面尺寸

每日热梗接口使用 24 小时缓存；抓取失败时会自动回退到经典备用梗池。当前文案组合仍以本地规则为主，下一步可接入多模态 AI 做更细致的表情识别与梗语境判断。
