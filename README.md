# 梗友 — 表情包生成器网页原型

这是一个可以直接在 VS Code 中运行的 Next.js 网页项目。

## 在 VS Code 中运行

1. 用 VS Code 打开整个 `meme-friend-web` 文件夹。
2. 打开 VS Code 终端。
3. 第一次运行先执行：

   ```bash
   npm install
   ```

4. 启动开发预览：

   ```bash
   npm run dev
   ```

5. 打开终端里显示的本地网址，通常是 `http://localhost:3000`。

## 当前功能

- 输入朋友说的话
- 上传并预览朋友照片
- 选择五种梗图文案风格
- 选择热点话题标签
- 模拟生成三张候选表情包
- 选择结果并保存 PNG
- 支持手机和桌面尺寸

当前版本是交互原型，文案生成使用本地规则。下一步可接入多模态 AI、实时热点数据和真正包含原照片的高清导出。
